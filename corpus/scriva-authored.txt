# What Scriva writes, written by Scriva.
#
# `cargo xtask author` runs this through the application's own commands — the
# ones its menus and keys run — and saves the result as
# docx/scriva-authored.docx, which is then measured against Word like every
# other document here. The others measure how Scriva reads; this one measures
# what it writes, which is where a new document's defaults and a table's cell
# widths both went wrong without any document to say so.
#
# One command a line, `#` starts a comment. The words are the menus' own:
#   type <text>              types the text; in double quotes where its end
#                            spaces matter
#   key <keys>               one press: Enter, Tab, Backspace, Home, End,
#                            ArrowDown, A ... (egui's names), with ctrl+,
#                            shift+ or alt+ in front
#   table <rows> <columns>   Insert ▸ Table
#   style <id>               a paragraph style by its id: Heading1, Normal
#   align start|center|end|both
#   size <points>   line-spacing <lines>   indent <steps>   borders on|off
#   bold  italic  underline  strike  superscript  subscript  clear-formatting
#   page-break  bullets  numbers  select-all  undo  redo  merge-cells
#   edit-header  edit-footer  close-chrome  page-number  page-of-pages
#   update-toc
#   expect bold|italic|underlined|plain "<text>"
#   expect style <id> "<text>"
#                            what the written document holds: authoring
#                            passes over these, and a test reads the document
#                            back and holds it to them, blanks included
#
# A change here changes the document, and `cargo xtask author` is how it is
# written again; the reading is renewed with it, and LAYOUT.md re-recorded.
